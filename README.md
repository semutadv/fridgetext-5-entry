One line, written for the make.fun bounty "The 3AM Fridge Text": the
text a smart fridge sends its owner at 3am. The milk expires tomorrow
and, honestly, so does the fridge; meanwhile its owner has opened it
six times tonight just to stare. It is the voice of an appliance that
has been awake all night and has started keeping score.

## Running it

`node main.ts` clears the output directory's contents and writes the
text to `/output/entry.txt` as plain UTF-8 text.
